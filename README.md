
# 👽 Jogo do Marciano

Um jogo de adivinhação desenvolvido em Java, no qual o jogador precisa encontrar um Marciano escondido em uma das 100 árvores.

## 🎮 Sobre o projeto

O jogo foi desenvolvido como projeto de prática de lógica de programação e tem como objetivo trabalhar conceitos fundamentais da linguagem Java.

## 🚀 Funcionalidades

- Menu principal interativo.
- Três níveis de dificuldade: Fácil, Médio e Difícil.
- Geração aleatória da localização do Marciano.
- Dicas indicando se o número correto é maior ou menor.
- Sistema de pontuação e ranking dos 10 melhores resultados.
- Validação das entradas do jogador.
- História e instruções disponíveis no menu.

## 🛠️ Tecnologias utilizadas

- Java
- Scanner
- Random
- Estruturas condicionais e de repetição
- Métodos e vetores (arrays)

## ▶️ Como executar

É necessário ter o Java instalado no computador.

1. Baixe os arquivos deste repositório.
2. Abra o terminal na pasta do projeto.
3. Compile o programa:

```bash
javac Main.java
```

4. Execute:

```bash
java Main
```

## 📚 Objetivo de aprendizagem

Praticar lógica de programação, estruturas de controle, métodos, arrays e manipulação de entradas do usuário.
